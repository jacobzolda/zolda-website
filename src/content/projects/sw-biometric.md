Senior Design capstone project: Drexel University, Electrical & Computer Engineering
(2025–2026).

A wearable biosensor platform for psychophysiological research. A wrist-worn device
streams Electrodermal Activity (EDA/GSR), Photoplethysmography (PPG), and motion
(gyroscope) data to a desktop application that processes the signals in real time and
gives researchers a live view into a subject's physiological state.

As software lead, I built the Python / NeuroKit2 pipeline performing tonic/phasic EDA
decomposition, artifact mitigation, and real-time visualization, along with the PyQt
GUI that serves as the application hub for the ESP32 and sensors.
