A collection of programming coursework from Drexel University:

- **GitHub: [Data Structures and Algorithms](https://github.com/jacobzolda/Data-Structures-and-Algorithms)**
  (C) — foundational data structures and algorithms built from scratch with explicit
  memory management, including a Huffman compression encoder and a breadth-first-search
  solver using a custom queue.
- **GitHub: [Modern Processor Design](https://github.com/jacobzolda/Modern-Processor-Design)**
  (C) — trace-driven architecture simulators, including a branch predictor with 2-bit
  saturating counters, a configurable set-associative cache, the SHIP cache-replacement
  policy, and a DRAM memory controller with multi-bank parallelism and request-queue
  scheduling.
- **GitHub: [Nand2Tetris](https://github.com/jacobzolda/Nand2Tetris)** — coursework
  following the Nand2Tetris curriculum, building a computer from NAND gates up.
- **GitHub: [Embedded C Programs](https://github.com/jacobzolda/Embedded-C-Programs)** —
  embedded systems coursework in C.
